# Asset credits · V18

All shipped assets are local. The migration script `tools/import_existing_assets.py` imports selected assets from the project's previously published commit `35edc3d5d494fb0d7a45ae617e608ea4f4221cb4` and repacks embedded nature textures / PBR maps to 512px. Build and runtime do not invoke this migration or download assets.

## Original character and procedural art

`assets/models/teacher_mom_chibi.glb` is the project's original Blender-generated mother in a pastel-blue Vietnamese áo dài, created by `tools/build_teacher_mom.py`. The retained character uses the existing project's broad reference cues. Source photographs are not shipped or embedded.

Clouds, architecture, classroom pupils, family characters, flowers, particles, analytic sky and graphic interface are procedural project code. The Web Audio pentatonic soundtrack is generated by original project code; no third-party recording is redistributed.

## Quaternius · CC0

- [Stylized Nature MegaKit](https://quaternius.com/packs/stylizednaturemegakit.html): `tree_common.glb`, `tree_twisted.glb`, `bush_flowers.glb`.
- [Ultimate Stylized Nature](https://quaternius.com/packs/ultimatestylizednature.html): `bush_ultimate.glb` retained as a small authoring resource.
- Files were previously packed from the existing project's `agentkaerf/FreeModels` mirror. V18 preserves the geometry and downsizes embedded textures. No paid engine-specific shader package is included.

## Kenney · CC0

- [Furniture Kit](https://kenney.nl/assets/furniture-kit): bench, bookcase, books, chair, coffee table, floor lamp, laptop, potted plant, rug, sofa and TV.
- [Car Kit](https://kenney.nl/assets/car-kit): sedan.
- The prior project imported these files from the `Hidencod/tge-assets` public mirror. The character and furnishings are migrated from the project's published branch.

## Poly Haven · CC0

[Poly Haven's asset license](https://polyhaven.com/license) permits use, modification and redistribution of its CC0 assets. V18 ships only 512px base color, OpenGL normal and roughness maps for `forest_floor`, `wood_floor`, `white_plaster_02` and `concrete_floor`, migrated from the existing published build.

Legacy HDRIs, scanned props and oversized surface textures are not needed by this runtime and are not included in the new build.

## Runtime libraries

Three.js is MIT licensed and bundled locally by esbuild. The existing project code remains under its MIT license. Dependency versions and integrity hashes are recorded in `package-lock.json`.
